# DeepSeek 补偿权益与批量操作优化

- 新增 DeepSeek 模型服务异常额外补偿 **500 积分**领取，支持自动领取及手动一键领取全部启用账号，**2026/10/22 23:59:59（北京时间）前领取**。
- 在“账号池 → 管理操作 → 额度与批量管理”直接执行，确认后开始，无需复选框。弹窗显示当前账号、进度以及完成后的成功/失败数量与本次领取积分。
- 自动检查统一由“定时任务 → 每日检查并领取权益”管理，默认每天一次，读取官方返回的积分、截止时间和领取状态。保留一次性手动补偿入口，移除 DeepSeek 专属自动任务及自动设置菜单；旧任务升级时迁移，保留启停状态。本期截止后每日权益任务继续运行，支持该官方接口后续提供的新活动；其他接口的新福利需要另行接入。
- 领取后刷新余额和到期快照，成功记录按账号和活动保存；超时先核对官方状态，避免立即重复领取。
- 修复“刷新全部”由浏览器逐账号请求的问题，改为一次 POST 提交后台批量任务，显示进度与成功/失败/跳过数量。
- 补齐补偿、刷新、成长任务、猫猫旅行批量按钮的准备及执行状态、禁用与重复点击保护。关闭进度弹窗后后台继续运行，可重新查看；同类型后台任务并发提交复用执行中的任务。

资格及到账结果以官方为准；账号忙碌或受保护时顺延补偿领取。补偿记录与刷新结果只包含脱敏账号标识和活动字段。
